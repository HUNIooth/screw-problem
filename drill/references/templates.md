# 양식

빈 칸은 "해당 없음"이나 "확인 필요(누구에게)"로 적고 지우지 않는다.

---

## 질문지.md (진행자용)

```markdown
# <업무명> 인터뷰 질문지

- 일시: / 대상: <이름, 부서, 역할> / 진행: / 예상 시간: 30분
- 미리 받을 것: <사전 질의서 회신, 샘플 파일, 양식>

## 확인할 가설
| # | 가설 | 근거 | 확인 질문 번호 |
|---|---|---|---|

## 질문
| # | 갈래 | 질문(현업 말로) | 왜 묻나 | 메모 |
|---|---|---|---|---|
| 1 | 목적 | | | |
| 2 | 한 건 따라가기 | | | |
| 3 | 판단 기준 | | | |
| 4 | 예외 | | | |
| 5 | 숫자/정답 | | | |

## 끝나기 전에
- 정답 사례 받을 수 있는지
- 다음에 누구를 만나야 하는지
- 오늘 정리를 언제 어떻게 확인받을지
```

## 사전질의서.md (현업 배포용)

글로 적어 오기 쉬운 것만 넣는다. 판단과 예외는 현장에서 묻는다.

```markdown
# <업무명> 사전 질의서

바쁘신데 감사합니다. 아는 만큼만 적어 주시고, 모르는 칸은 비워 두셔도 됩니다.

1. 이 업무를 하루(또는 한 달)에 몇 건 정도 처리하시나요?
2. 한 건 처리에 보통 몇 분 걸리나요?
3. 이 업무를 하는 인원은 몇 명인가요?
4. 처리할 때 여는 시스템, 파일, 양식 이름을 적어 주세요.
5. 참고하는 규정이나 매뉴얼이 있다면 이름을 적어 주세요.
6. 가능하면 최근 처리 건 샘플 1~2개를 보내 주세요(개인정보는 가려 주세요).
7. 이 업무에서 가장 바꾸고 싶은 점 하나를 적어 주세요.
```
