# 양식

필요한 칸만 쓴다. 빈 칸은 '확인 필요(누구)'.

## 질문지.md (진행자용)

```markdown
# <업무명> 인터뷰 질문지
- 일시 / 대상(이름, 부서) / 예상 30분 / 미리 받을 것:

| # | 갈래 | 질문(현업 말로) | 왜 묻나 |
|---|---|---|---|

끝나기 전에: 정답 사례 받기, 다음에 만날 사람, 오늘 정리 확인 방법
```

## 사전질의서.md (현업 배포용)

```markdown
# <업무명> 사전 질의서
아는 만큼만 적어 주세요. 모르는 칸은 비워 두셔도 됩니다.
1. 하루(한 달) 처리 건수
2. 한 건 처리 시간
3. 이 업무를 하는 인원
4. 여는 시스템, 파일, 양식 이름
5. 참고하는 규정이나 매뉴얼
6. 최근 처리 건 샘플 1~2개 (개인정보는 가려 주세요)
7. 가장 바꾸고 싶은 점 하나
```

## 요건정리.md

```markdown
# <업무명> 요건 정리
- 작성 <YYYY-MM-DD> / 대상 <이름, 부서> / <n>회차 / 확정 <n>, 정리 중 <n>

## 목적
- 요청 해결책(원문): "<그대로>"
- 실제 목적: / 되면 달라지는 것(숫자):

## 현행 흐름 (최근 한 건)
| 순서 | 하는 일 | 입력, 파일 | 판단 | 결과 남기는 곳 |

## 요건
| ID | 현업 원문 | 정리된 요건 | 근거 사례 | 확인 상태 |
| U-01 | "<그대로>" | | | 정리 중 |

## 판단 기준과 예외
| 판단 또는 예외 | 규칙 문장 | 출처(규정/암묵) | 빈도 |

## 숫자와 정답 사례
- 건수 / 한 건 시간 / 인원 / 오류 빈도:
- 정답 사례 경로 (못 받았으면 위험으로 적기):

## 다음 회차 질문
| 질문 | 누구에게 | 왜 |
```
