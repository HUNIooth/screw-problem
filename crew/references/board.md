# `_crew/` 양식

처음 역할을 정한 세션이 `_crew/`를 만들 때 쓴다. 짧게, 한 항목 한 줄.

## 역할.md
```markdown
# 세션 역할 (추가만, 세션별 최신 줄이 유효)
시각 | 세션 | 역할 | 범위 | 상태
2026-11-03 09:30 | S1 | 킥오프 | 전체 | 진행 중
```

## 지시.md
```markdown
# 사용자 지시 (추가만, 원문 그대로)
번호 | 시각 | 원문 | 관련
D-S1-001 | 2026-11-03 09:35 | "결과는 엑셀 말고 CSV로" | R-02
```

## 사용자_검토.md
```markdown
# <과제명> 사용자 검토
이 한 장만 보면 됩니다. 자세한 경과: history.md

## 지금
- 단계 / 다음 / 막힌 것:
- 정할 것 (최대 3개):

## 이번 확인 지점
### <커밋 확인 M1-c1 / 풀 수 없는 모호함>, <시각>
- 한 일 / 볼 것 / 검토 결과 / 추천:
- 내 결정 (사용자 작성):

---
## 지난 확인 지점 (최근 것이 위)
```

## 작업 파일
```markdown
# working_raw_log.md (추가만)
시각 | 단계 | 한 일 | 파일 | 결과

# 상태.md (덮어쓰기)
- 갱신 / 단계 / 다음 행동 / 막힌 것 / 알릴 것 / 대기 질문 / R별 검증

# 응답.md (추가만)
C | 반영, 일부 반영, 반영 안 함 | 이유 | 대안 | 바꾼 파일
```

## 노티 파일
```markdown
# 요청.md (추가만)

# 노티.md (추가만)
시각 | 급함/보통 | 제목 | 내용 | 사용자 답(D 번호)
```


