# Crew

| 역할 | 하는 일 | 지침 |
|---|---|---|
| 킥오프 | README 필수 요구사항을 빠짐없이 뽑아 요구사항, 계획, 세션별 시작 문장을 쓴다. 끝나면 노티로 바뀐다 | [role-kickoff.md](references/role-kickoff.md) |
| 작업 | 산출물을 만든다 | [role-worker.md](references/role-worker.md) |
| 노티 | 지시와 어긋나면 수정 요청, 사용자가 알아야 할 것만 알린다 | [role-noti.md](references/role-noti.md) |
| 기록 | 로그를 history.md로 정리한다 | [role-history.md](references/role-history.md) |

- 권한은 사용자 하나에서 나온다. 노티가 스스로 생각한 개선안은 사용자 승인 뒤에만 작업에 간다.
- 사람이 보는 문서는 `_crew/사용자_검토.md` 한 장.
- 역할은 어떤 AGENTS.md에도 쓰지 않는다. 그 폴더의 모든 세션이 읽기 때문이다.

## 0. 역할 정하기

1. `~/.screw-problem/설정.md`, `_crew/역할.md`, `_crew/EXECUTION.md`를 읽는다.
   - 설정이 '단일 세션'이면 crew를 쓸 수 없다고 알리고 `$when-you-encounter-problem`를 권한다. 사용자가 이번만 허용하면 지시.md에 남기고 진행한다.
   - 설정 파일이 없으면 멀티에이전트를 허용하는지 이 자리에서 묻는다.
2. 첫 메시지에 역할이 분명하면(예: "$crew 작업으로 시작한다") 묻지 않고 등록한다. 없거나 이미 쓰는 역할과 겹치면 묻고 턴을 끝낸다: 0 킥오프 / 1 작업 / 2 노티 / 3 기록 / 4 직접 지정. 추천은 EXECUTION.md가 없으면 킥오프, 있으면 아직 아무도 안 맡은 맨 위 세션.
3. 세션 이름(S1, S2...)을 정해 `역할.md`에 한 줄 추가하고 해당 지침을 읽고 시작한다. `_crew/`가 없으면 [references/board.md](references/board.md) 양식으로 만든다.

## 1. `_crew/` 파일

| 파일 | 쓰는 쪽 | 방식 |
|---|---|---|
| 역할.md | 각 세션 | 추가만. 상태가 바뀌면 새 줄, 세션별 최신 줄이 유효 |
| 지시.md | 지시를 받은 세션 | 추가만. 번호는 `D-<세션>-<순번>` |
| 사용자_검토.md | 킥오프, 이후 노티 | 덮어쓰기. 사용자 작성 칸 보존 |
| REQUIREMENTS.md, PLAN.md, EXECUTION.md | 킥오프 | 덮어쓰기 |
| working_raw_log.md, 응답.md | 작업 | 추가만 |
| 상태.md | 작업 | 덮어쓰기 |
| 요청.md, 노티.md | 노티 | 추가만 |
| history.md | 기록 | 덮어쓰기 |

- 남의 파일은 읽기만 한다. 작업 레인이 여럿이면 작업 파일에 `-A`, `-B`를 붙인다.
- 추가만 하는 파일은 `cat >> 파일 <<'EOF'`로 끝에 붙인다. 통째로 다시 쓰면 다른 세션이 쓴 줄이 사라진다. 정정은 새 줄로.
- 시각은 `YYYY-MM-DD HH:MM`. 파일 내용은 짧게, 한 항목 한 줄.

## 2. 공통 규칙

- 사용자 지시는 어느 세션에서 받든 원문 그대로 지시.md에 남긴다.
- 진행 상태, 미결 결정, 다음 행동은 자기 파일에 남긴다. 대화가 길어져 자동 요약되거나 세션을 다시 켜도 파일에서 이어 간다.
- 사용자 알림은 노티만 보낸다.
- 기다릴 때는 대기 스크립트로 잠든다.

```
python3 <스킬 폴더>/scripts/wait_change.py --state _crew/.wait-<세션>.json --timeout 600 <파일들>
```

- 바뀐 파일과 읽을 줄 범위만 알려 준다. 처음 실행하면 기존 내용 전체가 범위다.
- 범위를 빠짐없이 읽는다. 길면 나눠 읽고, 출력이 잘렸으면 더 작게 나눠 다시 읽는다.
- 다 읽은 뒤 완료를 표시한다. 완료 전에는 다시 실행해도 같은 범위를 또 알려 준다. "읽는 사이 바뀜"이 나오면 다시 기다려 새 범위를 읽는다.

```
python3 <스킬 폴더>/scripts/wait_change.py --state _crew/.wait-<세션>.json --done
```

- Codex에서 명령이 아직 돈다고 나오면 다시 실행하지 말고, 같은 세션을 빈 입력으로 이어 기다린다. 대기 시간은 런타임 지침을 따른다.
- 사용자가 말을 걸면 대기를 끊고 먼저 답한다.
