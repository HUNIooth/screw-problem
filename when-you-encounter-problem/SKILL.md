# When You Encounter Problem

바로 만들지 않는다. 아래 순서만 지키고, 세부는 사용자에게 물어 채운다.

1. **찾기:** 묻기 전에 작업 폴더, README, 기존 자료를 본다. 확인한 것, 모르는 것, 추정을 나눠 보여 준다.
2. **문답으로 구체화:** 사용자만 알고 결과를 바꾸는 것만 한 번에 최대 3개 묻는다. 고르는 질문은 선택지와 추천, 사실은 열어서. 보냈으면 턴을 끝내고 답을 기다린다. 사용자가 "됐다"고 하거나 더 물어도 결과가 안 바뀌면 멈춘다.
3. **문제 정의:** 누가, 무엇 때문에 곤란하고, 무엇을 받으면 끝나며, 무엇은 하지 않는지 한 문단으로 쓰고 확인받는다.
4. **할 일 목록:** `TODO.md`에 한 줄 한 가지 일과 통과 기준. 위험한 모름은 맨 앞 시험으로.
5. **지침 4종 초안:** AGENTS, PLAN, ENVIRONMENT, HANDOFF. 양식은 [references/templates.md](references/templates.md). 빈 칸은 지어내지 말고 양식의 질문으로 사용자에게 묻는다. 초안을 보여 주고 문답하며 고친다.
6. **넘기기:** 실행 가능 / 조건부 / 더 알아야 함 중 하나와 다음 행동을 알린다.

지킬 것
- 짧게 쓴다. 개조식, 한 항목 한 줄, 되풀이 금지.
- 추정을 사실로 쓰지 않는다. 원본과 기존 AGENTS.md를 덮어쓰지 않는다.
- 사람이 보는 곳은 HANDOFF.md 맨 위 '지금' 하나. 현재 상태만 두고 끝난 질문은 지운다.
- 설정 파일 `~/.screw-problem/설정.md`가 있으면 따른다.
