# 양식

칸마다 확인한 것만 쓴다. 모르면 오른쪽 질문을 사용자에게 묻는다(한 번에 최대 3개).

## TODO.md
```markdown
# <주제> 할 일
- [ ] 0 시험: <위험한 모름> | 통과: <> 
- [ ] 1 <한 가지 일> | 통과: <테스트나 확인 방법> | 선행: 0
```

## AGENTS.md
| 칸 | 모르면 물을 것 |
|---|---|
| 역할과 목표 | 이 에이전트가 끝내야 하는 것은? |
| 권한과 금지 | 어디까지 써도 되나? 하면 안 되는 일은(삭제, 외부 전송, 설치, 푸시)? |
| 일하는 방식 | 어디서 멈춰 확인받나? 커밋은 언제? 테스트는 어떻게? |
| 사용자 기준 | (작업 중 사용자 답 중 계속 적용될 것을 원문과 함께 쌓는다) |
| 완료 조건 | 무엇이 되면 끝인가? |

## PLAN.md
| 칸 | 모르면 물을 것 |
|---|---|
| 문제 정의 | 3단계에서 확인한 한 문단 |
| 요구사항과 검증 | 꼭 되어야 하는 것은? 무엇을 보면 됐다고 아나? |
| 범위 밖 | 이번에 하지 않는 것은? |
| 결정 기록 | (정한 것과 이유를 한 줄씩) |

## ENVIRONMENT.md
| 칸 | 모르면 물을 것 |
|---|---|
| 작업 루트, 런타임, 패키지 | (직접 확인. 못 하면 미확인) |
| 실행과 테스트 명령 | 어떻게 돌리고 확인하나? |
| 입력 데이터와 산출물 위치 | 원본은 어디고, 결과는 어디에 두나? |
| 권한과 외부 서비스 | 네트워크, 외부 API, 새 패키지 설치를 써도 되나? |
| 비밀값 | 위치만 쓴다. 값은 쓰지 않는다 |
