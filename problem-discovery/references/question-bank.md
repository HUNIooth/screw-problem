# 유형별 추가 질문

SKILL.md의 여섯 축 위에 얹어 쓴다. 해당 유형만 읽고, 조사로 답이 나오는 질문은 묻지 말고 직접 확인한다.
여러 유형이 섞이면 주 유형 하나를 정하고 나머지는 빈틈 확인용으로만 훑는다.

## 목차
- 업무 프로세스 자동화
- 문서/보고서/발표
- 앱/도구 개발
- 데이터 분석/검수
- 조사/연구
- 영상/콘텐츠 제작
- 의사결정 지원

---

## 업무 프로세스 자동화

- 지금은 누가, 어떤 순서로, 무엇을 보고 처리하나? 한 건 처리에 얼마나 걸리나?
- 입력은 어디서 오나(시스템/메일/파일), 형식이 매번 같은가?
- 예외는 얼마나 자주, 어떤 종류가 있나? 지금 예외는 누가 어떻게 처리하나?
- 사람이 반드시 확인/승인해야 하는 지점은 어디인가? (규정/감사 요건)
- 자동화 결과가 틀리면 누가 언제 알아채나? 되돌릴 수 있나?
- 전부 자동화인가, 사람 보조(초안/검토 대상 표시)인가?

## 문서/보고서/발표

- 누가 읽고, 읽고 나서 무엇을 결정/행동하나?
- 정해진 양식/분량/제출 형식(HWP/PDF/PPT)이 있나? 참고할 이전 문서가 있나?
- 꼭 들어가야 하는 수치/사실의 출처는 어디인가?
- 결론을 이미 정해 두고 근거를 모으는 문서인가, 결론을 찾는 문서인가?
- 검토/결재 단계는? 마감은 초안 기준인가 최종 기준인가?

## 앱/도구 개발

- 누가 어떤 환경(사내망/윈도우/모바일)에서 쓰나? 설치가 가능한가?
- 기존 시스템과 연결해야 하나(DB/API/파일 공유)? 접근 권한이 있나?
- 데모/PoC인가 실제 운영인가? 운영이면 누가 유지보수하나?
- 반드시 되어야 하는 핵심 흐름 하나는 무엇인가? (나머지는 희망)
- 보안/개인정보 제약은? 외부 API/클라우드를 써도 되나?

## 데이터 분석/검수

- 원천 데이터는 어디 있고 원본인가? 얼마나 많고 품질은 어떤가?
- 정답/기준은 무엇인가(규정/매뉴얼/이전 판정)? 기준끼리 충돌하면 무엇이 우선인가?
- 놓치는 것(누락)과 잘못 잡는 것(오탐) 중 무엇이 더 비싼가?
- 결과를 사람이 어떤 형태로 확인하나(표/마킹 화면/보고서)?
- 한 번 하고 끝인가, 반복 실행되는가?

## 조사/연구

- 이 조사로 답하려는 질문은 정확히 무엇인가? 답이 나오면 무엇이 달라지나?
- 이미 알고 있거나 가설이 있나? 반박 증거도 찾아야 하나?
- 믿을 만한 출처의 기준은? (공식 문서/논문/사내 자료/실측)
- 얼마나 깊이: 개요 한 장인가, 근거 달린 비교표인가?
- 시점이 중요한가(최신 가격/규정 개정)?

## 영상/콘텐츠 제작

- 어디에 올리나(공모전/사내 교육/SNS)? 규격/길이/심사 기준은?
- 핵심 메시지 한 문장은? 보는 사람이 무엇을 기억하고 나가야 하나?
- 출연자/촬영본/기존 소재가 있나? 저작권/라이선스 제약은?
- 톤/참고 영상은? 피해야 할 표현은?
- 생성 도구 비용/계정 한도는?

## 의사결정 지원

- 누가 언제까지 무엇을 정해야 하나? 선택지는 이미 정해졌나?
- 판단 기준과 가중치는? (비용/위험/속도/정치적 고려)
- 결정을 되돌릴 수 있나? 되돌리는 비용은?
- 결정권자가 이미 기울어 있는 안이 있나?
- 필요한 것은 추천 하나인가, 중립적 비교인가?
