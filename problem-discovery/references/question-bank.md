# 유형별 추가 질문

SKILL.md의 여섯 축 위에 얹어 쓴다. 해당 유형만 읽고, 조사로 답이 나오는 질문은 묻지 말고 직접 확인한다.
여러 유형이 섞이면 주 유형 하나를 정하고 나머지는 빈틈 확인용으로만 훑는다.

## 목차
- 업무 프로세스 자동화
- 앱/도구 개발
- 데이터 처리/검수

---

## 업무 프로세스 자동화

- 지금은 누가, 어떤 순서로, 무엇을 보고 처리하나? 한 건 처리에 얼마나 걸리나?
- 입력은 어디서 오나(시스템/메일/파일), 형식이 매번 같은가?
- 예외는 얼마나 자주, 어떤 종류가 있나? 지금 예외는 누가 어떻게 처리하나?
- 사람이 반드시 확인/승인해야 하는 지점은 어디인가? (규정/감사 요건)
- 자동화 결과가 틀리면 누가 언제 알아채나? 되돌릴 수 있나?
- 전부 자동화인가, 사람 보조(초안/검토 대상 표시)인가?

## 앱/도구 개발

- 누가 어떤 환경(사내망/윈도우/모바일)에서 쓰나? 설치가 가능한가?
- 기존 시스템과 연결해야 하나(DB/API/파일 공유)? 접근 권한이 있나?
- 데모/PoC인가 실제 운영인가? 운영이면 누가 유지보수하나?
- 반드시 되어야 하는 핵심 흐름 하나는 무엇인가? (나머지는 희망)
- 보안/개인정보 제약은? 외부 API/클라우드를 써도 되나?

## 데이터 처리/검수

- 원천 데이터는 어디 있고 원본인가? 얼마나 많고 품질은 어떤가?
- 정답/기준은 무엇인가(규정/매뉴얼/이전 판정)? 기준끼리 충돌하면 무엇이 우선인가?
- 놓치는 것(누락)과 잘못 잡는 것(오탐) 중 무엇이 더 비싼가?
- 결과를 사람이 어떤 형태로 확인하나(표/마킹 화면/보고서)?
- 한 번 하고 끝인가, 반복 실행되는가?
